# Pixel zone :rocket:

Projeto de estudo desenvolvido com `HTML` e `CSS`, com foco em boas práticas de uso do `CSS Grid`.

## Funcionalidades

- **Layout responsivo** com ajustes para mobile (320px), tablet (768px) e desktop (1024px e 1440px)
- **Galeria em mosaico** com 7 imagens, montada com `grid-template-areas`
- **Navegação por âncoras** no menu, com rolagem suave até cada seção
- **Botão com efeito hover** e chamada para a galeria

## Tecnologias

HMTL · CSS

## Como executar

Clone o repositório e abra `index.html` no navegador. :computer:
